## PART 1: PURE MEMORY-BASED IDENTIFICATION TESTS 🧠
* loves asking you to identify compounds using these tests. Memorize them perfectly.*

| Test Name | Reagent Used | What it Tests For | Positive Result |
|-----------|--------------|-------------------|-----------------|
| **Bromine Water** | `Br2` in `CCl4` | Alkenes & Alkynes (Unsaturation) | Brown color disappears (colorless) |
| **Baeyer's Test** | Cold, dil. alkaline `KMnO4` | Alkenes & Alkynes | Purple color disappears, brown ppt forms |
| **Tollens' Test** | `AgNO3` + `NH4OH` | **Aldehydes ONLY** (Not ketones) | Silver mirror forms on test tube |
| **Fehling's Test** | `CuSO4` + `NaOH` / Rochelle salt | **Aliphatic Aldehydes ONLY** | Brick-red precipitate (`Cu2O`) |
| **Iodoform Test** | `I2` + `NaOH` | Methyl Ketones & Secondary Alcohols with methyl | Yellow precipitate (`CHI3`) |
| **Lucas Test** | `ZnCl2` + conc. `HCl` | Differentiating 1°, 2°, 3° Alcohols | 3° = immediate cloudiness/oil layer |
| **2,4-DNPH Test** | 2,4-Dinitrophenylhydrazine | Carbonyls (Aldehydes & Ketones) | Yellow / Orange / Red precipitate |

## PART 2: THE "MAGIC REAGENTS" (Oxidation & Reduction) ⚙️
*You must know exactly what each reagent does to functional groups.*

### 1. Oxidizing Agents (Adding [O])
* **Strong (KMnO4 / K2Cr2O7 + H2SO4):**
 * `Primary Alcohol` ➔ `Aldehyde` ➔ `Carboxylic Acid`
 * `Secondary Alcohol` ➔ `Ketone` *(Stops here)*
 * `Tertiary Alcohol` ➔ *No reaction / Resists oxidation*
 * `Alkyl Benzene (Toluene)` ➔ `Benzoic Acid` *(Always oxidizes side chain!)*

### 2. Reducing Agents (Adding [H])
* **Strong (LiAlH4):**
 * `Carboxylic Acid` ➔ `Primary Alcohol`
 * `Aldehyde` ➔ `Primary Alcohol`
 * `Ketone` ➔ `Secondary Alcohol`
* **Mild (NaBH4):**
 * Reduces Aldehydes & Ketones ONLY. *(Does NOT reduce carboxylic acids or esters).*
* **Specific Reductions (Carbonyl to Alkane C=O ➔ CH2):**
 * **Clemmensen:** `Zn-Hg / HCl` *(Best for Ketones)*
 * **Wolff-Kishner:** `N2H4 / KOH` *(Best for Aldehydes)*

## PART 3: CORE REACTIONS & CONVERSIONS 🔄
*These are the exact reactions you need to write down and practice.*

### 1. Preparation & Reactions of Alkyl Halides (RX)
* **Preparation (From Alcohols):**
 * `R-OH + SOCl2 ➔ R-Cl + SO2 + HCl` *(Best method!)*
 * `R-OH + PCl5 ➔ R-Cl + POCl3 + HCl`
* **Reactions (Elimination vs. Substitution):**
 * *Aqueous KOH favors Substitution (SN):*
 `CH3-CH2-Br + KOH(aq) ➔ CH3-CH2-OH + KBr`
 * *Alcoholic KOH favors Elimination (E):*
 `CH3-CH2-Br + KOH(alc) ➔ CH2=CH2 + KBr + H2O`

### 2. Reactions of Benzene (Electrophilic Substitution)
*Benzene rings undergo substitution, NOT addition.*
* **Nitration:**
 * `Benzene + HNO3 ➔ Nitrobenzene` *(Catalyst: H2SO4 at 50-55°C)*
* **Halogenation:**
 * `Benzene + Cl2 ➔ Chlorobenzene + HCl` *(Catalyst: FeCl3 or AlCl3)*
* **Friedel-Crafts Alkylation:**
 * `Benzene + CH3-Cl ➔ Toluene (Methylbenzene) + HCl` *(Catalyst: AlCl3)*
* **Friedel-Crafts Acylation:**
 * `Benzene + CH3-CO-Cl ➔ Acetophenone + HCl` *(Catalyst: AlCl3)*

### 3. Directing Groups on Benzene
* **Ortho/Para Directing (Activating):** Push electrons into ring.
 * Examples: `-OH`, `-NH2`, `-CH3`, `-OCH3`.
 * *Exception:* Halogens (`-Cl`, `-Br`) are Ortho/Para but *deactivating*.
* **Meta Directing (Deactivating):** Pull electrons away.
 * Examples: `-NO2`, `-COOH`, `-CHO`, `-CN`, `-SO3H`.

### 4. Important Aliphatic Additions (Markovnikov's Rule)
* **Markovnikov's Rule:** Adding `H-X` to an unsymmetrical alkene. The `H` goes to the Carbon with MORE hydrogens.
 * `CH3-CH=CH2 + H-Br ➔ CH3-CH(Br)-CH3` *(2-Bromopropane is major product)*
* **Ozonolysis:** Cleaves the double bond using Ozone (`O3`).
 * `CH2=CH2 + O3 ➔ (Ozonide) ➔ 2 HCHO` *(Formaldehyde)*

## PART 4: IMPORTANT NAME REACTIONS 🏆
* **Cannizzaro Reaction:** For aldehydes with NO alpha-hydrogens (e.g., Formaldehyde `HCHO`).
 * `2 HCHO + 50% NaOH ➔ CH3OH + HCOONa` *(One oxidizes, one reduces = Disproportionation)*
* **Aldol Condensation:** For aldehydes/ketones WITH alpha-hydrogens (e.g., Acetaldehyde `CH3CHO`).
 * `2 CH3CHO + Dilute NaOH ➔ CH3-CH(OH)-CH2-CHO` *(Forms an Aldol)*
* **Esterification:**
 * `CH3COOH + CH3CH2OH ⇌ CH3COOCH2CH3 + H2O` *(Catalyst: Conc. H2SO4)*
 * *Note: The OH comes from the acid, and the H comes from the alcohol.*
* **Wurtz Reaction:** Used to double the carbon chain of an alkane.
 * `2 CH3-Cl + 2 Na ➔ CH3-CH3 + 2 NaCl` *(In dry ether)*
